# skill：事实确认

## 事实库与源码

- **事实库**：从 MC 源码里确认过的事实，每条都带源码引用（文件 + 行号）。用 `fact_search` 查
- **源码基准**：1.21.11 的反编译源码（客户端与服务端合一，只有 `.java`）。`mc_source_search` 搜、`mc_source_read` 读一段；路径都相对基准，读不到基准以外的文件
- 反编译源码里的局部变量名多是 `i` / `bl` 之类，方法名、字段名、类名是可信的

## 怎么确认

1. 先 `fact_search`：库里已经有、引用没有标 `stale`，就用它；需要看原文再 `mc_source_read` 它引用的那几行
2. 库里没有就查源码
3. 结论有三种：
   - **源码支持**：用 `fact_write` 写入，然后回复结论与依据
   - **源码不支持**：回复源码里实际是怎样；实际情况本身是一条事实，可以写入
   - **查不清**：说明查到了哪一步、卡在哪里，不写入

## `fact_write` 的规则

- 每条事实必须附 1–5 条源码引用 `{ file, lines: [start, end] }`，`file` 用搜索结果里的路径；每条最多 80 行。引用不存在、行号越界会被拒绝
- 名字已存在时必须写 `replaces`（它当前的修订号），表示有意修订；不是同一件事就换个名字
- 写入成功会返回几条相近的已有事实：重复了可以改成修订，矛盾了回头再确认
